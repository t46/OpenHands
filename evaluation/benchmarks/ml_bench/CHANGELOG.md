## [1.0.0] - 2025-12-02

### 🎉 初回リリース
ML-Bench評価システムの環境起因の問題に対する包括的な修正を実装。

### ✨ 新機能

#### 1. prefix_codeバグ自動修正 (run_infer.py:79-120)
- **関数**: `fix_prefix_code_bugs(prefix_code: str) -> str`
- **目的**: データセットに含まれる誤ったprefix_codeを自動修正
- **修正内容**:
  - GitHub URLの修正: `/blob/main/` → `raw.githubusercontent.com`
  - `pip install -e .` にエラーハンドリングを追加
  - 複数行コマンドを`&&`で連結
- **対象**: Instance 272, 264
- **効果**: Instance 264で成功確認

#### 2. パス探索の柔軟性向上 (run_infer.py:123-169)
- **関数**: `find_run_script(runtime, task_path, max_depth=3)`
- **目的**: サブディレクトリ内の`run.sh`も検出
- **機能**:
  - 直接パスをまずチェック
  - 見つからない場合、最大3階層のサブディレクトリを探索
  - 複数見つかった場合は最も浅いパスを選択
- **対象**: Instance 164, 145, 230, 129, 260, 172
- **効果**: Instance 145で成功確認
- **⚠️ 問題**: 文字列マッチングによる誤判定バグあり（2025-12-03に修正）

#### 3. BERTモデル自動準備 (run_infer.py:172-233)
- **関数**: `setup_bert_models(runtime, task_path, prefix_code)`
- **目的**: prefix_codeで参照されるBERTモデルを自動ダウンロード
- **機能**:
  - prefix_codeから`BERT_BASE_DIR`を抽出
  - モデルの存在確認
  - 存在しない場合、Google Cloud Storageからダウンロード
- **対象**: Instance 49, 33, 41, 45, 37, 53
- **実際の動作**: モデルは既にDocker環境に存在していた
- **効果**: 環境は正常、タスク失敗はエージェントのコードバグ

#### 4. GLUEデータ自動準備 (run_infer.py:236-278)
- **関数**: `setup_glue_data(runtime, task_path)`
- **目的**: BERT fine-tuningで必要なGLUEデータセットを自動ダウンロード
- **対象**: Instance 33
- **効果**: 環境は正常、タスク失敗はエージェントのコードバグ

## 設計原則

すべての修正は以下の原則に基づいています:

1. **環境の責任範囲のみを修正**
   - エージェントが解決すべき問題には介入しない
   - 評価システムのバグや不公平な条件のみを修正

2. **ベンチマークの設計意図を尊重**
   - タイムアウトは修正しない（エージェントの効率性評価）
   - prefix_codeがないタスクは修正しない（エージェントの自律性評価）

3. **透明性の維持**
   - すべての修正内容をログに記録
   - 何が修正され、なぜ修正されたかを明示

4. **評価の正確性を最優先**
   - 誤判定を排除
   - 環境問題とエージェント問題を明確に区別
